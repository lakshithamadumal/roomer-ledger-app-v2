# 🏠 Roomer – Shared Expense & Room Finance Manager

Roomer is a modern expense management application built with Flutter, designed for roommates, boarding house members, university students, and shared living groups.

The app helps users track shared expenses, manage debts, approve transactions, and maintain transparency within a room.

---

## ✨ Features

### 🔐 Authentication

* Secure Sign Up & Login
* User Profile Management
* Room-based Access Control

### 🏠 Room Management

* Create Rooms
* Join Rooms using Room ID
* Room Approval System
* Admin Management

### 💰 Expense Management

* Add Shared Expenses
* Automatic Debt Calculation
* Track Who Owes Whom
* Expense History

### ✅ Approval Workflow

* Expense Verification System
* Member Approval Requests
* Prevent Invalid Expense Entries

### 📊 Analytics

* Spending Overview
* Expense Statistics
* Financial Insights
* Member Contribution Tracking

### 🔔 Notifications

* Expense Approval Requests
* Room Activity Updates
* Important Alerts

### 🌍 Multi-Currency Support

* LKR
* USD
* EUR
* GBP
* INR
